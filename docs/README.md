## Conventions

- **Decisions** live in `decisions.md`. Topic docs link to decision IDs (e.g. `D-003`) rather than repeating the rationale.
- **Fact provenance**: in hardware notes, *(verified)* means it was checked against a product page or datasheet. *(to verify)* means it comes from memory or inference and must be checked before relying on it.
